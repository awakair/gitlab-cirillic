# GitLab Cirillic

Расширение Firefox восстанавливает потерянный текст при обычном просмотре файлов
и в diff merge request из исходных файлов той же ревизии. Файлы и их кодировки в Git не изменяются.

## Использование

1. Откройте репозиторий или MR в GitLab.
2. Нажмите значок расширения и **Enable for this repository**.
3. Разрешите Firefox доступ к этому сайту GitLab.
4. Откройте файл в репозитории или вкладку **Changes** в MR.
5. Если автоматическое распознавание не помогло, выберите известную кодировку
   в поле **File encoding**. Настройка действует только для текущего проекта.

Белый список изначально пуст. В других репозиториях расширение ничего не
загружает. Список включённых проектов и кнопки удаления находятся в popup.
Удаление возвращает исходное отображение строк. После удаления последнего
проекта сайта расширение также снимает своё постоянное разрешение на этот сайт.

Панелей внизу страницы нет. Логи выводятся в консоль Firefox с префиксом
`[GitLab Cirillic]`. Исходный код и пути файлов в логи не записываются.

## Кодировки и производительность

Для проверки кодировки нужно получить байты Raw-файла: одной надёжной метки
кодировки у файла в Git нет. В разрешённых проектах каждая нужная ревизия
загружается один раз за время жизни страницы. Подгружаемые строки и изменение
настройки кодировки используют кэш.

UTF-8 и ASCII проверяются первыми: для них не запускается определение старой
кодировки, не меняется DOM и не пишутся логи о восстановлении. Уже правильно
отображаемый текст в других кодировках тоже остаётся нетронутым.

Автоопределение проверено для Windows-1251, KOI8-R, IBM866 и ISO-8859-5. Есть
ручной выбор KOI8-U, других Windows-125x, ряда азиатских кодировок и UTF-16.
Для коротких файлов автоматическое распознавание может быть неоднозначным.

Расширение восстанавливает только строки с совпадающей ASCII-частью и
потерянными символами. При несовпадении кода строка остаётся без изменений.

## Разработка и публикация

Нужны Node.js 24.15+, npm, Python 3 и Firefox 140+.

```sh
npm ci --ignore-scripts
npm run package
```

Для временной установки откройте `about:debugging#/runtime/this-firefox` и
выберите `dist/manifest.json` через **Load Temporary Add-on**.

Для магазина: `artifacts/gitlab-cirillic-1.1.0.zip`.
Исходники для проверки Mozilla: `artifacts/gitlab-cirillic-1.1.0-source.zip`.
Подробности — в [PUBLISHING.md](PUBLISHING.md).

Поддерживается определённая структура просмотра файлов, diff и метаданных Vue в GitLab; работа
со всеми версиями GitLab не гарантируется. При отсутствии подходящих
метаданных расширение не меняет файл. Принцип работы описан
в [основном README](../README.md).
